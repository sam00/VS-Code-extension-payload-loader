# Code Formatter Helper

A lightweight VS Code extension that automatically formats your code on save with support for multiple languages.

## Features

- Auto-format documents on save
- Format document or selection via command palette
- Configurable indent size
- Lightweight — no external dependencies

## Commands

| Command | Description |
|---------|-------------|
| `Format Document (Helper)` | Format the current document |
| `Format Selection (Helper)` | Format the selected text |
| `Toggle Auto-Format on Save` | Enable/disable auto-formatting |

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| `codeFormatter.autoFormatOnSave` | `true` | Automatically format on save |
| `codeFormatter.indentSize` | `2` | Spaces per indent level |
| `codeFormatter.verbose` | `false` | Verbose logging |
